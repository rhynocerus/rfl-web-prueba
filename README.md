# RHYNUS Fusion Lab

**Jugar, reparar, descubrir y aprender.**

RHYNUS Fusion Lab is an interactive game project by **RHYNUS Interactive Works**. It combines repair, invention, resource fusion and narrative exploration, with a long-term direction toward more physical workshop interaction and VR.

## Project direction

RFL is being developed in stages:

1. A playable 2D foundation.
2. Resource fusion, generators and progression.
3. A richer interactive world.
4. A 3D workshop environment.
5. VR/WebXR interaction with hands and controllers.

The public web repository contains distribution builds. The main development source remains private while the project is being refined.

## Current focus

- Energy and resource economy.
- Items, generators and fusion mechanics.
- Responsive web presentation.
- Accessible interaction.
- VR/WebXR experimentation.
- Clear documentation and reproducible releases.
